Automated Exam Timetable Scheduler

Generated conflict-free exam schedules across 15+ academic branches under complex resource constraints. Offline AI · Privacy-preserving2025

AI Medical Report Summarizer

Converts complex medical PDFs into dual summaries — simplified for patients, technical for doctors — using React and a locally-run Ollama (gemma2:2b) model, with 100% local processing. Handled scanned and handwritten reports via pdfplumber extraction and Tesseract/Pillow OCR, with JWT authentication, logging, and error handling built in for reliability.

Movie Analysis & Recommendation System

Classified movies with 84.12% accuracy using Logistic Regression and Naive Bayes, after feature engineering on genre, cast, and budget metadata. Paired with a content-based recommender using Bag of Words and cosine similarity, deployed as an interactive Streamlit app for real-time recommendations.
